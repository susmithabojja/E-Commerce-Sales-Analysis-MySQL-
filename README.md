# E-Commerce Sales Analysis Using MySQL
# Project Overview
This project focuses on analyzing e-commerce sales data using MySQL to generate meaningful business insights. The analysis explores customer behavior, product performance, order trends, payment methods, and revenue performance.
The goal is to transform raw data into actionable insights that can help businesses understand sales patterns, identify top-performing products, and make better business decisions.
# Project Objectives
- Analyze overall sales and revenue performance.
-Identify top-selling products and product categories.
-Understand customer purchasing behavior.
-Analyze monthly sales trends.
-Identify high-value customers.
-Examine order status and cancellation rates.
-Analyze payment methods and payment performance.
-Calculate important business KPIs.
